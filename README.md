# goldenranks.com

GoldenRanks is a web application that features a real-time leaderboard where users can submit their name and a contribution amount. The leaderboard ranks users by their total contributed amount, with special highlights for the top contributors. Payments are securely processed via PayPal, and users can see their estimated rank before submitting. The backend is powered by Node.js and SQLite, while the frontend is built with React.

- Real-time leaderboard with ranking and highlights
- Secure PayPal payment integration
- User-friendly interface for submitting and viewing ranks
- Terms & Conditions and Privacy Policy included
